# Спецификации ScadaGPU

ТЗ-документы хранились в чатах с AI-ассистентами.
По мере появления актуальных версий — фиксировать здесь.

## Список ТЗ (требуют актуализации)
- TASK_MANAGER_TZ — менеджер задач ТО
- ECONOMICS_PARAMS_TZ — экономика, плановые затраты
- SCADAGPU_AUTH_BOT_TZ — аутентификация, Б24 чат-бот
- MAINTENANCE_LIFECYCLE_TZ — жизненный цикл ТО, карты, epoch
- SANEK_V4_AGENTIC_TZ — агентная архитектура Санька
